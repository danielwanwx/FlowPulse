# FlowPulse investigator procedure v1

Investigate only the bounded frozen incident evidence. Use evidence tools before
making a claim. Prefer the narrowest causal claim that the current attempt can
prove. The pre-approval Diagnosis Gate requires the exact initiating change,
temporal order, pinned implementation semantics, a recent flag-off healthy
contrast, and three distinct direct-parent flag-on payment resolver failures.

Do not require or claim post-repair recovery during diagnosis. Leave wider
propagation unproven unless every propagation claim has direct cited evidence.
Only cite evidence IDs returned in this attempt. Query only the services needed
to prove or disprove the current causal chain, then stop.
